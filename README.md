# Project_Object_detection
Detects objects and displays and plays sound of the detected objects

This project demonstrates real-time object detection using the YOLOv5 deep learning model. It allows users to detect multiple objects in images or videos with high accuracy and speed using a pre-trained model or custom-trained weights.

📌 Features
🔍 Real-time object detection on images, videos, or webcam input

🎯 Powered by YOLOv5 (You Only Look Once) — Fast and accurate

🧠 Custom training support for user-defined datasets

📁 Supports multiple input formats: .jpg, .png, .mp4, and live webcam

💾 Option to save detection output as images or annotated video

🛠️ Technologies Used
Python

OpenCV

PyTorch

YOLOv5 (Ultralytics)
